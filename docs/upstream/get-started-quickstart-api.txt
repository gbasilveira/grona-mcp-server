Quickstart: Public API
This quickstart calls the Grona Public API, part of Grona Embed, from a terminal. You check that the Grona Embed snippet is on a page, create a website campaign, open its variation in the visual editor and set the campaign live. Use it to see the request and response shapes before you build the calls into your own platform.
Before you start
Section titled “Before you start”
Get a Grona Embed workspace.
The Public API is available on request: email
support@grona.ai
to request one.
Install the Grona Embed snippet
on the page you want to change. Campaigns created through the API run through it, and the Public API does not work with the script on the Website pages. See
Install the Grona Embed snippet
.
Set a page variable on that page.
A campaign shows only to visitors whose page sets a variable you name to a value you name. This quickstart uses
window.audience_id = 'returning_buyer';
in an inline script above the snippet.
Generate a secret API key
in the Grona Embed dashboard, under
Settings > Secrets
. Only a workspace Owner or Admin sees that tab. The key looks like
gro_ed_<keyId>_<secret>
and is scoped to one workspace. It is a server-side secret: never put it in a browser, an app or a repository.
Put the key in an environment variable,
so the commands below never contain it:
Terminal window
export
GRONA_SECRET_KEY
=
"gro_ed_<keyId>_<secret>"
In production, load it from your secrets manager instead.
Every request goes to
https://services.grona.ai/api/public/v1
with the key in the
Authorization
header. The workspace comes from the key; it is never part of the URL or the body.
Caution
There is no sandbox. These calls act on your live workspace. The campaign you create starts paused, so visitors see nothing until the last step.
Make the calls
Section titled “Make the calls”
Check that the snippet is on the page.

-sS

$GRONA_SECRET_KEY

"Content-Type: application/json"

Create a campaign.
This creates a general campaign, with one variation, on the home page.
name
,
url
,
segmentId
and
segmentValue
are required:
segmentId
is the name of your page variable and
segmentValue
is the value it must hold.
externalId
is your own id for the campaign.
Terminal window
curl
-sS
https://services.grona.ai/api/public/v1/campaigns
\
-H
"Authorization: Bearer
$GRONA_SECRET_KEY
"
\
-H
"Content-Type: application/json"
\
-d
'{
"name": "Free delivery bar for returning buyers",
"url": "https://shop.example.com/",
"segmentId": "audience_id",
"segmentValue": "returning_buyer",
"externalId": "CMP-1024"
}'

New campaigns always start
paused

To create an A/B test or target several pages, see

Open the editor link in a browser.
Copy
variations[0].editUrl
from the response into your browser. It opens the visual editor on your page, where you build the variation. The link is a secret and expires 15 minutes after
generatedAt
, so open it straight away and do not store, log or forward it.
If it has expired, ask for a new one:
Terminal window
curl
-sS
https://services.grona.ai/api/public/v1/variations/edit-link
\
-H
"Authorization: Bearer
$GRONA_SECRET_KEY
"
\
-H
"Content-Type: application/json"
\
-d
'{"variationId": "671a3c90e4b0a1f2c3d40012"}'
When you have saved the variation, open its
previewUrl
to check it on your page. Preview records nothing. See
Visual editor links
.
Set the campaign live.
You can use Grona’s campaign id or your
externalId
in the path:
Terminal window
curl
-sS
-X
PATCH
https://services.grona.ai/api/public/v1/campaigns/CMP-1024/status
\
-H
"Authorization: Bearer
$GRONA_SECRET_KEY
"
\
-H
"Content-Type: application/json"
\
-d
'{"status": "live"}'
{
"data"
: {
"status"
:
"live"
},
"meta"
: {
"workspaceId"
:
"65e8a1c47d2f9b03e6a15c42"
}
}
Grona then rebuilds your workspace’s script and refreshes the CDN, so allow a few minutes before visitors see the variation. Only visitors whose page sets
audience_id
to
returning_buyer
see it. To stop the campaign, send
{"status": "paused"}
to the same endpoint.
If a call fails
Section titled “If a call fails”
Errors share one shape, with a machine-readable
code
and a readable
message
:
{
"error"
: {
"code"
:
"conflict"
,
"message"
:
"`externalId` \"CMP-1024\" is already used by another campaign in this workspace."
}
}
conflict
on create means a campaign with that
externalId
already exists. That makes
externalId
a safe way to retry a create: a retry cannot make a duplicate. See
Errors
for every code.
